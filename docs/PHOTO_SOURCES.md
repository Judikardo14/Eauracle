# Demo photo sources and rights

The demo photos are intentionally **not included in this repository**. They are
ignored by Git because the project does not currently have confirmed
redistribution rights for them.

The local demo expects files named:

```text
app/photos/<Zone>_<number>.jpg
```

For example:

```text
app/photos/Bonou_1.jpg
app/photos/Porto-Novo_1.jpg
```

## Current local demo assets

The photos used during local testing are illustrative images associated with
flooding in southern Benin. They were obtained from third-party media sources
(including Mongabay Afrique / EchoSciences). Their presence on a developer's
local machine does **not** grant permission to redistribute them.

Before publishing or recording a public demo, replace them with:

- photographs taken by the project team with permission; or
- images released under a licence that permits redistribution, such as a
  suitable Wikimedia Commons image.

Record the exact source URL, author, licence and any permission in this file
before using a replacement image publicly.
